核心管理层、高频 AI 岗位、知识型员工。需要企业 AI 任务执行、深度调研、多模态内容生成、企业知识问答、策略中心与 Agent 安全。

→

→

以协作和业务系统使用为主，暂不需要完整企业 AI 的办公室员工。

→

一线员工只需移动端接任务、填表、参会；主管需要全端汇总数据。

06

采购建议

三步完成方案选型。

STEP 01

判断客户规模与预算

  • 10–100 人小团队 → 优先推荐豆包精英订阅（打包价性价比高）或豆包团队订阅（灵活 1 席起）
  • 100 人以上中大型企业 → 优先推荐企业旗舰或尊享，搭配用量套餐
STEP 02

确认 AI 使用深度

  • 只是日常办公辅助（写文档、做 PPT、简单问答）→ 团队 / 精英订阅 + 基础用量包即可
  • 需要企业知识问答、aily 工作流、项目 AI、CodeM → 企业旗舰起步
  • 需要 API 调用、高管模式、深度定制 Agent → 企业尊享 + 600 万点以上用量包
STEP 03

评估飞书协同需求

  • 已有飞书套件 → 直接加购豆包工作席位和用量包
  • 新客户从零开始 → 推荐豆包企业订阅（含飞书协同底座）
  • 有大量一线员工 → 混合配置：办公室买企业版 + 一线买 A1 / A2
